# Pet Battle 成长与战斗系统

## 设计来源

战斗状态采用 [boardgame.io](https://github.com/boardgameio/boardgame.io)（MIT）的核心思路：

- 战斗数据是可序列化的纯状态
- 玩家只能提交有限的合法行动
- 每次行动生成下一回合状态和战斗日志
- UI 与规则分离，后续可以接机器人、回放和联网服务器

同时参考 [pkmn/engine](https://github.com/pkmn/engine)（MIT）的 `update + valid choices` 边界设计，但没有复制宝可梦角色、数值、技能、属性克制或素材。Pet Battle 的战斗公式与宠物天赋均为本项目原创规则。

## 白卡与成长

新拍摄的宠物统一生成白卡，不随机宠物稀有度，也不自带装备。宠物的长期差异来自：

1. 宠物品类的基础数值
2. 创建时从该品类专属池中无重复抽取的 3 个种族天赋
3. 等级成长
4. 三个装备槽：头部、身体、挂件

当前支持猫咪、狗狗、鸟类、兔兔、鼠类和爬宠六个品类，每个品类有六个候选天赋。

## 装备来源

- 签到：金币与装备券
- 装备箱：消耗 1 张装备券，只抽装备，不抽宠物
- 冒险：消耗体力，胜利后获得金币和装备
- 概率：普通 64%、稀有 28%、史诗 8%；高级冒险提供小幅稀有度加成

## 战斗规则

- 速度较高者先行动
- 快速出击：低倍率攻击，获得 25 能量
- 蓄能猛击：高倍率攻击，消耗 50 能量
- 防守姿态：本回合受到的伤害减半，获得 15 能量
- 防御按照固定系数抵消攻击，最终伤害至少为 1
- 每次攻击有 90%—110% 的小幅波动
- 暴击造成 1.5 倍伤害，暴击率最高 35%
- 闪避会完全避开一次攻击，闪避率最高 25%

核心公式：

```text
基础伤害 = 攻击 × 技能倍率 × 波动 - 防御 × 0.48
最终伤害 = max(1, 基础伤害 × 暴击倍率 × 格挡倍率)
```

所有核心规则位于 `src/game.ts`，自动化测试位于 `src/game.test.ts`。
