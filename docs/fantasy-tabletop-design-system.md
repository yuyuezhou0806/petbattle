# 暖爪旅舍：奇幻宠物桌游视觉系统

## 世界与空间

首页是一张真实可用的“暖爪旅舍”工坊桌，而不是产品介绍页。深胡桃木承担空间底色，烛光只标记视觉焦点；图鉴、委托、补给、地图、试炼和公会都以桌面实体物件出现。

## 材质与色彩

- 胡桃木：`#2B190F` / `#493021`，用于空间、木牌与普通卡。
- 皮革：`#70422C` / `#3C2119`，用于图鉴、档案与厚重边缘。
- 羊皮纸：`#E0C78F` / `#A98755`，用于技能、任务与说明文字。
- 黄铜：`#B88339` / `#E4BC6A`，用于铆钉、边线和重要资源。
- 炉火琥珀：`#E89639`，只用于焦点和反馈，不铺满界面。
- 石与月银：`#455B5D` / `#E2E8DD`，用于稀有卡。

所有表面至少由主体色、亮边、暗边三层组成。阴影短而有方向，用来说明物件与桌面的接触关系，不使用大面积模糊光晕。

## 字体层级

- 旅舍标题与宠物铭牌：衬线体，24–34px，厚重字重。
- 物件名称：衬线体，16–20px。
- 正文与任务：系统无衬线体，10–14px。
- 铭文与编号：全大写或短中文，7–10px，加宽字距。

## 控件

- 主要按钮为榫接木牌：7px 小圆角、2px 倒角边、4px 接触阴影。
- 次要按钮为浅石或羊皮纸材质。
- 按下时整体下沉 3px，同时将阴影缩短到 1px。
- 导航是并排的雕刻木签，选中态靠下沉和黄铜边识别。
- 资源以金币、装备券和体力瓶实体筹码展示。

## 原创宠物卡

卡牌比例为 `5:7`。外轮廓使用上下不同收分的不规则厚框，中央是切角立绘窗；出战能量位于左上符文石，元素位于右上印记，稀有度晶石位于底部中央。宠物名称位于独立浮雕铭牌，技能放在羊皮纸带，攻击与生命使用两枚方向相反的合金战斗石。综合评分、编号和六维属性只出现在收藏详情，不挤入战斗卡面。

- 普通：旅行木材、单层边框、无持续动效。
- 稀有：月银和青玉、双层边框。
- 史诗：暗晶与雕刻纹、少量反光。
- 传说：炉火黄金、四层结构、短促箔片和有限粒子。
- 神话：星兽合金、异色晶石、更多但克制的局部粒子。

烈焰、潮汐、森林通过立绘窗底材、符文笔画和局部边色表达，不只做整体换色。所有名称、数值、技能和编号均为真实文本。

## 动效与响应式

桌面端卡牌 hover 抬升 8px并倾斜 1.2°；按钮和物件点击下沉 3–4px。开卡状态使用一次翻面、聚光消退和稀有度材质显现，不让所有元素持续漂浮。系统开启减少动态效果后，抬升、翻面和循环反光全部停用。

桌面端采用委托板—宠物祭台—物件架三列桌面构图；窄屏改为纵向游玩路径，优先展示资源、当前宠物、功能物件和委托。卡牌缩小时保留评分、名字、稀有度、攻击和生命。
