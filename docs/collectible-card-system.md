# PAW//CORE 原创收藏卡系统

本系统用于 Pet Battle 的卡组、详情、对战选人和开卡场景。它借鉴成熟体育收藏卡对“评分—主体—名字—数据”的阅读顺序，但不使用任何体育游戏品牌、卡框轮廓、字体或原排版。

## 规格

- 标准尺寸：320 × 448，比例 5:7。
- 卡组尺寸：224 × 314；对战选人尺寸：144–154 × 202–216。
- 12 列网格，标准安全区 20px。
- 原创外形：顶部双肩切角、中央短冠槽、底部双斜切。
- 评分、定位、徽章、名字、等级、进化、属性和阵营均为真实文本。
- 宠物主体是独立透明 PNG/WebP，可以越过内框，但不能进入评分和属性安全区。

## 信息层级

1. 左上综合评分与战斗定位。
2. 右上稀有度代号与元素六边徽章。
3. 中央透明宠物主体。
4. 中下名称、等级、进化阶段、品类和羁绊。
5. ATK / DEF / SPD / VIT / TEC / LUK 六项属性。
6. 底部阵营、流派和收藏编号。

## 六项属性

| 缩写 | 名称 | 数据来源 |
| --- | --- | --- |
| ATK | 强袭 | 攻击 |
| DEF | 护甲 | 防御 |
| SPD | 迅捷 | 速度 |
| VIT | 体魄 | 生命值折算 |
| TEC | 技巧 | 速度与暴击折算 |
| LUK | 灵运 | 闪避与天赋数量折算 |

卡面属性只负责收藏展示，不改写现有战斗结算。

## 材质层级

- 普通 `BASE`：单层冷银框、拉丝纹、无粒子。
- 稀有 `EDGE`：双层彩釉边、细斜纹、轻边缘高光。
- 史诗 `SIGIL`：三层深色金属、虹彩刻线、低频反光。
- 传说 `CROWN`：金色冠边、放射箔纹、稀疏粒子和扫光。
- 神话 `ORBIT`：分段星陨轮廓、棱彩嵌片和轨道粒子。

## 状态与无障碍

- Hover：轻抬升；选中：外部刻线与“编入”角标。
- 锁定：机械锁片覆盖；受伤：红色裂痕；升级：边框脉冲。
- 开卡：背面同步状态，随后揭示正面。
- 系统开启“减少动态效果”时，扫光、抬升和脉冲均退化为静态展示。

主题集中在 `src/cardSystem.ts`，组件位于 `src/CollectiblePetCard.tsx`。新增宠物或稀有度时只添加数据/主题，不复制页面代码。
